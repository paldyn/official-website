Git 실행 환경

macOS 12 이상에서는 Git과 Git LFS가 앱에 포함되어 별도 Git 설치 없이 사용할 수 있어요.

macOS 11에서는 시스템 Git 2.38 이상이 필요해요. 다른 macOS에서도 원하면 설정에서 시스템 Git을 선택할 수 있어요.

원격 저장소 인증

기존 Git·SSH·키체인 설정을 사용해요. 앱 내 로그인은 제공하지 않으므로 원격 작업 전에 인증을 준비해 주세요.

새 Mac으로 옮긴 뒤에도 인증은 별도로 설정해야 해요.

설치와 업데이트

내려받은 DMG를 열고 Branch를 응용 프로그램 폴더로 끌어다 놓으세요. macOS가 앱을 확인할 수 없다거나 손상되었다고 알리면 열지 말고, 파일을 지운 뒤 알려 주세요.

설치한 뒤에는 Branch가 새 버전을 확인하고 내려받아요(설정 → 업데이트에서 바꿀 수 있어요). 설치는 직접 확인한 뒤에만 진행돼요.

Intel Mac, Windows, Linux는 첫 공개 베타에서 지원하지 않아요.
