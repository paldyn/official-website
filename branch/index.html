웹에서도 사용할 수 있나요?+

Branch는 내 컴퓨터의 저장소를 다루는 데스크톱 Git 클라이언트예요. 웹 버전은 없고, 이 페이지에서 Mac용과 Windows용 앱을 내려받을 수 있어요.

어떤 컴퓨터에서 사용할 수 있나요?+

Mac은 Apple silicon 모델에서 macOS 11 이상과 WebKit 16.2 이상이 필요해요.

Windows는 Windows 10·11(64비트, x64)에서 사용할 수 있어요. 화면 표시에 쓰는 Microsoft Edge WebView2 런타임이 없으면 설치 프로그램이 함께 설치해요.

Intel Mac과 Linux는 아직 지원하지 않아요.

Git을 따로 설치해야 하나요?+

macOS 12 이상에서는 앱에 포함된 Git과 Git LFS를 사용할 수 있어요. macOS 11에서는 시스템 Git 2.38 이상이 필요해요.

Windows에서는 따로 설치하지 않아도 돼요. 앱에 Git for Windows의 MinGit과 Git LFS, Git Credential Manager가 들어 있어요.

필요하면 설정에서 내 컴퓨터에 설치된 Git을 선택할 수 있어요. 기존 커밋 훅과 서명 설정도 그대로 쓸 수 있어요.

원격 저장소는 어떻게 연결하나요?+

기존 Git·SSH 설정을 그대로 사용해요. Mac에서는 키체인에 저장된 로그인을 쓰고 앱 내 로그인은 제공하지 않으므로, 원격 작업 전에 인증을 준비해 주세요.

Windows에서는 앱에 포함된 Git Credential Manager가 HTTPS 로그인이 필요할 때 로그인 창이나 브라우저를 열고, 로그인 정보를 Windows 자격 증명 관리자에 저장해요.

새 컴퓨터로 옮긴 뒤에도 인증은 별도로 설정해야 해요.

설치와 업데이트는 어떻게 하나요?+

Mac에서는 내려받은 DMG를 열고 Branch를 응용 프로그램 폴더로 옮기세요. macOS가 앱을 확인할 수 없다거나 손상되었다고 알리면 열지 말고, 파일을 지운 뒤 알려 주세요.

Windows에서는 내려받은 설치 파일(Branch_버전_x64-setup.exe)을 실행하세요. 관리자 권한 없이 내 계정에 설치돼요. 설치 파일에 아직 코드 서명이 없어 "Windows의 PC 보호" 창이 뜰 수 있어요. 이 페이지나 GitHub의 paldyn/Branch-releases에서 받은 파일이라면 추가 정보 → 실행을 눌러 설치하세요. 다운로드로 이동

앱이 새 버전을 확인하고 내려받으며, 설정 → 업데이트에서 바꿀 수 있어요. 설치는 직접 확인한 뒤에만 진행돼요.
